Server Backups

Automated off-site database backups for a privately operated Windows Server.

Privacy Policy Terms of Service

What it does

Server Backups is a private utility operated by the owner of im2slothy.com. It uses rclone to automatically upload backups of SQLite database files from the owner's personal Windows Server to the owner's Google Drive.

The utility is intended only for the owner's personal server administration and backup purposes. It is not offered as a service to the general public.

Why Google Drive access is needed

Google Drive authorization is used solely for backup storage. Server Backups uses the https://www.googleapis.com/auth/drive.file OAuth scope to create and manage its backup files and folders.

Google data is used only as necessary to create and manage backup files. The utility does not request unrestricted access to all existing Google Drive files.

How data is used

Server Backups does not sell user data, serve advertising, use Google user data for advertising, or provide data to advertisers. Google user data is not shared with unrelated third parties.

See the Privacy Policy for details about Google Drive access and stored credentials, and the Terms of Service for the utility's terms.
