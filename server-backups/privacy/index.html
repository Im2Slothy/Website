Server Backups Privacy Policy

Last updated: September 29, 2026

Purpose and operator

Server Backups is a private server-backup utility operated by the owner of im2slothy.com. It uses rclone to upload automated backups of SQLite database files from a privately operated Windows Server to the owner's Google Drive.

The application is intended only for the owner's personal and private use. It is not offered as a service to the general public.

Google Drive access

Server Backups uses Google OAuth with the https://www.googleapis.com/auth/drive.file scope. This scope provides limited, per-file access.

The application accesses Google Drive only to create, upload, list, update, and manage backup files and folders created or used by the Server Backups utility, within the access granted by this scope. Access is limited to items the utility creates or that the owner explicitly makes available to it.

The application does not request unrestricted access to all existing Google Drive files. Google Drive authorization and Google user data are used only for the server backup functionality described on the Server Backups homepage.

Credentials and backup storage

Google OAuth credentials and tokens may be stored securely on the privately operated server so automated backups can run without repeated manual authorization.

Backup database files are stored in the owner's Google Drive. The utility uses Google Drive as the off-site storage destination for these backups.

Use and sharing of Google user data

Google user data is used only as necessary to create and manage the utility's backup files.

  • Google user data is not sold.
  • Google user data is not used for advertising or provided to advertisers.
  • Google user data is not shared with unrelated third parties.

Revoking access

The owner can review and revoke Server Backups' access through their Google Account permissions. Select Server Backups and remove its access to Google Drive.

Revoking access prevents the utility from accessing Google Drive for further backups until it is authorized again. It does not itself delete backup files already stored in Google Drive; those files can be managed directly in Google Drive.
